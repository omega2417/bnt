# Issue → evidence → correction → manuscript location

Status vocabulary:

- **CONFIRMED** - independently reproduced by executing the deposited code.
- **NOT REPRODUCED** - the executed campaign does not yield the claimed value; the
  claim is withdrawn until the physical campaign supplies evidence.
- **NOT COMPARABLE** - the claim is not estimable as stated (undefined statistic,
  different testbed, or different data origin).
- **BLOCKED** - the claim requires the physical cyber range, which has not been run.

Paths are relative to `experiment/`.
