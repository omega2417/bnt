# AIDE-6 — система агентного проєктування складних технічних систем (Google Colab)

Самодостатній навчальний програмний проєкт за статтею *«Artificial Intelligence in the Design of Complex Technical Systems:
Integrating Engineering Knowledge, Multi-Objective Synthesis and Digital Twins»*. Наскрізний приклад — термінал супутникового
зв'язку Ka-діапазону.

## Вміст архіву

| Файл | Призначення |
|---|---|
| `AIDE6_agentic_design.ipynb` | ноутбук для Colab (без виводів — запускається з нуля) |
| `AIDE6_executed.ipynb` | той самий ноутбук, уже виконаний: усі графіки, таблиці й висновки |
| `aide6_outputs/` | артефакти виконаного запуску: рисунки, PROV-JSON, журнал, рішення, твердження, чернетки документів |
| `README.md` | цей файл |

## Як запустити в Google Colab

1. Відкрийте https://colab.research.google.com → **File → Upload notebook** → `AIDE6_agentic_design.ipynb`.
2. **Runtime → Run all**. На стандартному CPU це займає ≈ 3–6 хв. Встановлювати нічого не потрібно
   (NumPy, SciPy, pandas, scikit-learn, networkx, matplotlib, Numba уже є в Colab).
3. Наприкінці автоматично завантажиться `aide6_outputs.zip` з усіма артефактами.

Прапорці в першій кодовій комірці: `FAST=True` — швидкий режим (менше прогонів Монте-Карло); `INTERACTIVE=True` — рішення на
воротах G1–G6 вводить людина через `input()` (за замовчуванням вони імітуються за критеріями воріт і позначаються в журналі `engineer(simulated)`).

## Що реалізовано

* **Модель даних:** Requirement, Artefact, Claim, Evidence, Decision, ToolRun, ModelVersion; SHA-256 хеші.
* **Знання і дані:** провенанс у стилі W3C PROV-JSON, хеш-ланцюжок журналу, версіонований репозиторій артефактів, реєстр двійників.
* **Інструменти як MCP-сервери:** catalog, stage123, morph, mcda, twin, verif, uq, faults, bo, lab — з JSON-схемами входів/виходів, бюджетом, журналом.
* **Оркестратор:** автомат станів S1→G1→…→G6→DONE зі зворотними зв'язками 4→3, 5→3, 6→4; стан зберігається між сесіями.
* **Агенти:** А1–А6, критик К (окремий контекст, повторні розрахунки, пошук цитат, звірка хешів протоколів), Т (граф простежуваності, T_cov),
  Д (чернетки ТЗ, ПМВ, звіту, заявки), Б (конфіденційність, захист від ін'єкцій). Політика автономії λ(a).
* **Етапи 1–6:** вилучення знань з цитатами (ЛД1), каталог (C_Ф, дедуплікація), морфологічний простір 4608 → 1476 → 810, точний фронт Парето,
  NSGA-II, AHP/TOPSIS, новизна; цифровий двійник (Монте-Карло, ACM DVB-S2); V&V, LHS + ГП + індекси Соболя, відмови, байєсова оптимізація,
  Клоппер–Пірсон; імітатор стенда, GUM, валідація |E| ≤ 2u_val, калібрування, тепловий зсув осі, факторний план 2^(4−1), ізоляційний ліс, TRL.
* **ЛД6:** 50 впроваджених дефектів, абляції «без критика» і «без воріт».

## Статус даних

Усі параметри навчальні; патентні документи й результати випробувань синтетичні; ВММ імітується детермінованим `MockLLM`
(інтерфейс `LLMBackend` дає змогу під'єднати локальну модель). Результати показують, що процедура працює, а не характеристики реального виробу.
