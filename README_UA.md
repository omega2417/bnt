# Програмний проєкт до дисертації

**Тема (робоча):** Навчання структури та застосування баєсівських мереж для задач класифікації.

Проєкт реалізовано в середовищі **MATLAB** на базі бібліотеки **Bayes Net Toolbox (BNT)**
(автор — Kevin P. Murphy, ліцензія GNU LGPL) з додаванням власного програмного
модуля для навчання структури мережі, дискретизації даних методом MDL,
завантаження вибірок із бази даних та оцінювання якості класифікації.

> Цей файл (`README_UA.md`) призначений для експертної комісії та як основа для
> розділу «Програмна реалізація» дисертації. Оригінальний англомовний опис
> бібліотеки BNT наведено у файлі `readme.md`.

---

## 1. Призначення

Програма дозволяє:

- завантажити навчальну вибірку (з файлу або з бази даних MySQL);
- виконати **дискретизацію** неперервних ознак методом Fayyad & Irani (MDL);
- **навчити структуру** баєсівської мережі одним із 15 алгоритмів
  (PC, IC, BNPC, MWST, Naive, TAN, FAN, K2, MCMC, GS2, GES, MWST‑K2, HC, GS+T,
  MWST‑EM, TAN‑EM);
- побудувати мережу (BNET) з таблицями умовних імовірностей (CPD);
- виконати **класифікацію** з перевіркою якості (Hold‑Out, CV‑5, CV‑10);
- отримати **матрицю плутанини** (confusion matrix) та **точність** (correct rate);
- **порівняти** отриману структуру з еталонною мережею (правильні / пропущені /
  зайві / реверсовані ребра).

## 2. Вимоги до середовища

| Компонент | Версія / примітка |
|-----------|-------------------|
| MATLAB | R2018b або сумісна (перевірено на R2018b) |
| Bayes Net Toolbox (BNT) | у складі репозиторію, каталог `BNT/` |
| SLP (Structure Learning Package) | у складі репозиторію, каталог `SLP/` |
| GraphViz | для візуалізації графів (`draw_graph`, `graph_to_dot`) — опційно |
| MySQL + JDBC‑драйвер | лише для модуля завантаження з БД (`Utils/database/`) — опційно |

## 3. Встановлення та запуск

1. Клонувати репозиторій і відкрити його як робочу теку MATLAB.
2. Додати всі підкаталоги до шляху MATLAB:

   ```matlab
   cd <шлях-до-проєкту>      % тека, де лежить bntRoot.m
   addpath(genpathKPM(pwd)); % рекурсивно додає BNT, SLP, Utils, ...
   ```

3. (Необов'язково) Перевірити коректність встановлення BNT:

   ```matlab
   test_BNT            % штатний тест бібліотеки
   ```

4. Запустити демонстраційний експеримент класифікації (набір Iris):

   ```matlab
   iris_classified_demo
   ```

   > Демонстрація `iris_classified_demo` за замовчуванням читає дані з MySQL
   > (`get_default_mysql_data('iris')`). Якщо БД не налаштована — замініть
   > джерело даних на локальну матрицю або скористайтесь власною вибіркою
   > (див. розділ 4 файлу `docs/dysertacia/architecture_ua.md`).

## 4. Структура проєкту

```
.
├── BNT/          # Бібліотека Bayes Net Toolbox (стороння, GNU LGPL)
├── SLP/          # Structure Learning Package — алгоритми навчання структури
├── graph/        # Операції над графами (тріангуляція, junction tree, DAG)
├── HMM/          # Приховані марковські моделі
├── Kalman/       # Фільтр Калмана
├── KPMstats/     # Статистичні утиліти
├── KPMtools/     # Загальні утиліти
├── netlab*/      # Нейромережеві утиліти (Netlab)
├── GraphViz/     # Візуалізація графів
├── docs/         # Документація (у т.ч. dysertacia/ — матеріали до дисертації)
│
└── Utils/        # ►►► ВЛАСНИЙ КОД ПРОЄКТУ ◄◄◄
    ├── classified/       # Навчання структури + класифікація, оцінка якості
    ├── discretization/   # Дискретизація даних методом MDL (Fayyad & Irani)
    ├── database/         # Завантаження вибірок з MySQL
    ├── struct/           # Порівняння структур DAG з еталоном
    └── utils/            # Допоміжні функції (get_bnet, node_sizes, print_dag)
```

Повний перелік власних файлів (для лістингів у додатках дисертації) —
див. `docs/dysertacia/appendix_listings_ua.md`.

## 5. Типовий сценарій використання (pipeline)

```
Дані (файл / MySQL)
      │
      ▼
convert_to_num_matrix        ← перетворення cell → числова матриця
      │
      ▼
mdl_algorithm                ← дискретизація ознак (Fayyad & Irani, MDL)
      │
      ▼
learn_struct_and_classified  ← навчання структури + класифікація (CV/Hold‑Out)
      │
      ├──► confusion_matrix, correct_rate
      │
      ▼
computer_avg_classified      ← усереднення за повтореннями експерименту
      │
      ▼
compare_dag / print_dag      ← порівняння з еталоном, друк залежностей
```

## 7. Відтворюваність результатів

Для наукової частини зафіксуйте:

- версію MATLAB та ОС;
- конкретний коміт/тег репозиторію, на якому отримано результати;
- набір даних і параметри експерименту (алгоритм структури, метод перевірки,
  кількість повторень, `max_fan_in`, `order`, `score` тощо).
