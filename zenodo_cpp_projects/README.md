# Програмні проєкти до Розділу 3 — гібридна байєсівська просторова атрибуція джерел Wi-Fi

Три самодостатні програмні проєкти мовою **C++17**, що реалізують ключові
обчислювальні ядра **Розділу 3** дисертації «Моделі, алгоритми та програмно-
апаратна реалізація методології тактичної просторової ідентифікації». Кожен
проєкт:

- складається з **одного файлу** `src/main.cpp` без зовнішніх залежностей
  (лише стандартна бібліотека) — компілюється й запускається **як є** на
  [OnlineGDB](https://www.onlinegdb.com), у `g++`/`clang++` (>= C++17) чи MSVC;
- містить **вбудовану демонстраційну сцену** (виводить результат без введення);
- супроводжується `README.md`, `LICENSE` (MIT), `Makefile`, `CITATION.cff`
  та `.zenodo.json` для депонування на **Zenodo**;
- постачається окремим **ZIP-файлом** (тека `dist/`).

> Усі сцени — **аналітичні ілюстрації структури алгоритмів**, а не емпіричні
> результати. Конкретні числові робочі точки мають статус **to_be_validated**
> і підтверджуються в Розділі 4 (експериментальна валідація).

## Склад

| # | Проєкт | Підрозділ | Ядро | ZIP |
|---|---|---|---|---|
| 1 | **Адаптивне зважування сенсорів** | §3.3 | декомпонована вага `π·γ·κ·ρ` (eq. 3.1), доменні caps, rate limiter, гістерезис, weight trace | `dist/project1_adaptive_weighting.zip` |
| 2 | **Байєсівський posterior і MAP/HPD** | §3.4 | log-domain fusion RSSI×FTM (eq. 3.6–3.14), MAP, моди, HPD, зональна маса, out-of-map | `dist/project2_bayesian_posterior.zip` |
| 3 | **Дрейф-компенсація та FTM-якоріння** | §3.5 | латентний дрейф (Kalman+Huber, eq. 3.16–3.19), trusted-update gate, EIG (eq. 3.21) | `dist/project3_drift_ftm_anchoring.zip` |

Проєкти утворюють логічний конвеєр Розділу 3: **ваги (§3.3) → posterior (§3.4) →
дрейф/якоріння (§3.5)**. Вихід підсистеми зважування (вектор `w_s`) слугує
показником інформаційного внеску модальностей у злитті posterior; окрема оцінка
дрейфу захищає радіокарту від неконтрольованої корекції.

## Швидкий старт

**OnlineGDB:** відкрийте сайт → мова **C++** → вставте вміст відповідного
`src/main.cpp` → **Run**.

**Локально:**

```bash
cd project1_adaptive_weighting && make run
cd ../project2_bayesian_posterior && make run
cd ../project3_drift_ftm_anchoring && make run
```

або напряму, наприклад:

```bash
g++ -std=c++17 -O2 src/main.cpp -o app && ./app
```
