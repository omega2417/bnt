# Declarations, Data Availability and MDPI checklist

## Data Availability Statement

**While `data/` is the synthetic reference dataset (current state):**

> **Data Availability Statement:** The analysis pipeline, reference
> implementation, configurations, and attack recipes supporting this study are
> openly available in the accompanying repository. The `data/` directory of the
> current release contains a synthetic reference dataset provided to make the
> analysis reproducible; it is not experimental data and is labelled as such. The
> run-level experimental dataset will be deposited, and this statement updated
> with the archive DOI and version, before publication.

**Once real run-level data replace the synthetic dataset:**

> **Data Availability Statement:** The run-level experimental data, availability
> traces, attack scripts, framework configurations, and analysis code supporting
> the findings of this study are available in Zenodo at [DOI], version [release].
> The repository includes a data dictionary and the scripts required to reproduce
> the statistical analyses and Figures 5–11.

## Pre-submission checklist (from the review, mechanised where possible)

Run `make verify`. It confirms: 160 run-level rows with the declared design;
every availability trace present and parseable; recovery time and NRI
recomputable from the traces; the abstract's headline numbers reproduced from
`data/`; overhead below 6%. It reports **not submission-ready** until the
synthetic dataset is replaced and the Zenodo DOI is set — by design.
