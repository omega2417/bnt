# How the revised manuscript describes this supplement

The wording below paraphrases the revised manuscript (logistics-4699826). The bundle and the manuscript must say the same thing; if one changes, change the other.

**Section 2.9.** The Zenodo supplement [59] contains the protocol, hardware documentation and input-data templates of a preparatory three-node experiment (two mobile nodes and one stationary node) and an exploratory decision-support prototype, a small multilayer perceptron trained exclusively on synthetic observations generated from assumed distributions. The prototype produced no result reported in the article and has no measured predictive accuracy; it is mentioned only because it fixes the input fields that the event log must record during the field experiment of Section 4.6.

**Section 4.5.** The decision-support prototype in the supplement [59] was trained on synthetic observations only and has no measured accuracy.

**Data Availability Statement.** The supplement contains only synthetic, explicitly labelled data and input templates. Neither release contains measured field data, because no field measurements were made for the study.

Two points the manuscript should state consistently with this bundle:

1. The preparatory three-node experiment is **planned**; it has not been carried out.
2. The cited version should be 1.1.0. Version 1.0.0 contained a document that wrongly described the experiment as conducted (see README, "Correction of version 1.0.0").
