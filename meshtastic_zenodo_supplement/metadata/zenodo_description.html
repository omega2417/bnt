Supplement [59] to the manuscript Strengthening Operational Autonomy in Small and Medium-Sized Enterprise Logistics with Meshtastic Mesh Networks: Reference Architecture and Ex-Ante Model-Based Assessment. No experiment has been performed and the bundle contains no measured data. It contains a prospective protocol for a three-node Meshtastic experiment that has not been carried out, input-data templates, and an exploratory decision-support prototype (13-16-8-1 multilayer perceptron) trained exclusively on 3600 synthetic observations generated from assumed distributions. The prototype has no measured predictive accuracy and produced no result of the article; its synthetic hold-out scores are a software self-consistency check only. Correction: version 1.0.0 contained a document that wrongly stated that a three-node field experiment had been conducted; that document has been removed and version 1.0.0 should not be used. The article's economic-model and plotting scripts are not included. Manufacturer documents retain their original rights.
