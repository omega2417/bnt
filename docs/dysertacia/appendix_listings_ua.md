# Перелік власного коду для лістингів у додатках

Документ фіксує **межу оригінальності** проєкту: які файли є авторським внеском
(підлягають включенню в додатки дисертації у вигляді лістингів), а що є сторонньою
бібліотекою (наводиться лише посиланням на джерело, **не** копіюється в додатки).

> Загальна статистика репозиторію: **1535** файлів `*.m`, з них **власних — 18**
> (каталог `Utils/`). Решта (~1517) — бібліотеки BNT, SLP, Netlab, GraphViz тощо.

## 2. Що НЕ виносити повністю в додатки

| Файл | Причина |
|------|---------|
| `Utils/database/get_default_mysql_data.m` (1024 / 1730) | Це **не алгоритм**, а «зашитий» у код тестовий набір даних (Iris). У додатку достатньо навести перші 20–30 рядків як приклад формату; повний обсяг у лістинг не включати. |
| Увесь каталог `BNT/` | Стороння бібліотека (© K. Murphy, GNU LGPL) — лише посилання. |
| Каталоги `SLP/`, `netlab*/`, `graph/`, `HMM/`, `Kalman/`, `KPMstats/`, `KPMtools/`, `GraphViz/` | Сторонні компоненти — лише посилання. |

## 3. Оформлення лістингів (рекомендації)

- Шрифт моноширинний (Courier New / Consolas), 10–11 pt, одинарний інтервал.
- Перед кожним лістингом — заголовок із назвою файлу, напр.:
  *«Лістинг А.1 — Функція навчання структури `learn_struct_and_classified.m»`*.
- Кожен додаток починати з нової сторінки; нумерація — літерна (А, Б, В …) за ДСТУ.
- Якщо лістинг переноситься на кілька сторінок — повторювати заголовок з приміткою
  «(продовження)».
- Зберегти англомовні коментарі авторів у коді як є; **не перекладати** код.

## 4. Підсумкові цифри для тексту дисертації

- Власний програмний внесок: **18 файлів**, приблизно **1990** кодових рядків
  (без урахування «зашитого» тестового набору даних — приблизно **970** рядків
  прикладної логіки).
- Реалізовано: 1 конвеєр обробки даних, підтримка **15** алгоритмів навчання
  структури та **3** схем перехресної перевірки, метод дискретизації MDL,
  засоби порівняння структур та оцінювання якості класифікації.

> Команда для самостійної перевірки переліку власних файлів:
> ```bash
> find Utils -name '*.m' | sort
> ```
