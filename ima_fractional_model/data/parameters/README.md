# Parameters

The baseline synthetic parameters live in `config/ima_22node.yaml` (global
parameters and per-node / per-edge values) and are echoed to
`results/tables/table1_parameters.csv` by `reproduce_all.py`.

The prescribed ensemble sensitivity ranges (Table A2) are in
`config/ensemble_ranges.yaml`.

All values are synthetic / mechanism-oriented and are NOT calibrated to any real
or certified IMA platform.
