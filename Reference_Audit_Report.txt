2. GENERAL FORMATTING OBSERVATIONS
-----------------------------------
The references do NOT follow a single consistent citation style (neither
DSTU 8302:2015, APA, IEEE, nor Vancouver). Specific inconsistencies:

a) No explicit numbering in the source text—references appear as continuous
   paragraphs without [1], [2], … markers (they are implied by order).

b) Author name format is inconsistent:
   - Some use "Surname I.B." (Ukrainian standard): Хорошко В.О.
   - Some use full first name then surname: Аблуллах Фоуад Аль-Далваш
   - Some use Western order: Aaron Don M. Africa, …
   - Some mix both in the same entry: Oppenheim, A. V., Шафер Р. В.
     and R. W. Schafer (ref [93])

c) Journal title formatting is inconsistent:
   - Sometimes in quotes: «Безпека інформації»
   - Sometimes plain: Наукоємні технології
   - Sometimes with institution tag: Науковий журнал «Безпека інформації».НАУ
   - No italicization anywhere

d) Year/volume/issue/pages format varies widely:
   - "2021.С. 126-131" (no space before С.)
   - "2022.С. 200-205" vs. "2020. С. 45-55"
   - "Т. 10. № 1., 2020" (trailing comma+period)
   - "Vol. 8, № 4. July-August" (mixed Vol./№)
   - "рр." used instead of "pp." in English entries

e) DOI formatting issues:
   - Some have a space after "doi.org/ ": https://doi.org/ 10.18372/...
   - Some use "DOI:" prefix, others embed as URL
   - Some DOIs appear truncated

f) Page range separators vary: "С. 126-131", "С. 61– 66", "рр. 33 ‒ 56",
   "pр. 88–101" (note Cyrillic "р" in some, Latin "p" in others).

g) Conference proceedings mix city information inconsistently:
   "м. Київ. 2021 р., м. Київ, Україна" (city repeated twice in ref [9]).

4. REFERENCES THAT APPEAR POTENTIALLY PROBLEMATIC
---------------------------------------------------

a) Ref [7] (SITS`2021 / 2020 date mismatch): The 13th SITS conference
   is labeled 2021 but dated June 2020. One of these must be wrong.

b) Ref [36] ("33 с." for an encyclopedic reference book): Implausibly
   short. Likely a misprint.

c) Ref [44] ("М.Є." orphaned initials): Indicates a corrupted author list.

d) Ref [65] (two sources merged into one): Must be split.

e) Ref [67] ("Hau C. C." vs. real author C. H. Chen): Author name may
   be incorrect.

f) Ref [46] (Acustek site): The "https." is broken and the company
   website may no longer exist. Access dates of "05.06.2025" are future
   dates from the document's writing perspective.

g) Ref [55] access date "04.06.2025" for a 2002 regulation — unusual
   to cite access date for a legislative document.

h) Several references cite access dates of 2019 or 2025 but the
   underlying content is much older; this is fine for web resources
   but the formatting should be uniform.

6. RECOMMENDATIONS FOR FORMATTING
-----------------------------------

1. ADOPT A SINGLE CITATION STYLE consistently throughout. For a Ukrainian
   dissertation, DSTU 8302:2015 (Ukrainian bibliographic standard) is
   recommended. For an English translation, APA 7th or IEEE style is
   standard in cybersecurity/IT.

2. NUMBER ALL REFERENCES explicitly: [1], [2], …, [105].

3. STANDARDIZE AUTHOR NAMES: Use "Surname, I.B." format for all.
   For transliteration of Ukrainian names to English, follow the
   official Ukrainian transliteration standard (KMU Resolution 55/2010).

4. FIX ALL DOI URLS: Remove errant spaces (4 instances found).

5. USE CONSISTENT PAGE ABBREVIATIONS: "pp." for English, "С." for Ukrainian.
   Do not use Cyrillic "р" in English entries.

6. STANDARDIZE JOURNAL TITLE FORMAT: Italicize journal/book titles.
   Remove quotation marks unless they are part of the official title.

7. SPLIT REF [65]: Separate the Swets book and the SDR/CR web resource.

8. FIX AUTHOR ERRORS: Ref [44] (orphaned "М.Є."), Ref [28] (missing
   initials for Михайлевич), Ref [67] (verify author name).

9. REMOVE LINE-BREAK ARTIFACTS: Refs [75], [69] have hyphenated splits.

10. STANDARDIZE ACCESS DATES: Use consistent format "(accessed: DD.MM.YYYY)"
    and verify all web resources are still reachable.

11. VERIFY DATE in Ref [7]: SITS'2021 cannot have taken place in June 2020.

12. For the English translation: provide English translations of Ukrainian
    titles in square brackets after the original, per APA convention.
