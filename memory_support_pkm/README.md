# pgmem — provenance-governed асистент пам'яті

Програмна реалізація концептуальної рамки зі статті
**D. Prokopovych-Tkachenko, «Provenance-governed agentic AI for personal knowledge and memory support: a conceptual framework»**
разом із синтетичним датасетом, метаданими й статистичним аналізом людей з порушеннями пам'яті.

> ⚠️ **Усі дані синтетичні.** Жоден запис не відповідає реальній людині. Розподіли (вік, MoCA, PRMQ, CDR, частки
> тих, хто живе сам, тощо) — це проєктні припущення для етапу 1 протоколу оцінювання зі статті (прототип на
> синтетичних історіях), а не клінічні оцінки. Результати показують, як поводяться правила рамки, і не доводять
> користі для людей.

## Що реалізовано (відповідність статті)

| Стаття | Код |
|---|---|
| Рівн. (1) запис `r_i = (c, t, s, κ, σ, v, e)`, версії, спірні записи, видалення з мінімальним аудитом | `pgmem/model.py` |
| Рівн. (2) ескалація з бінарним гейтом `G_k`; рівн. (3) зниження стартового рівня після `m` епізодів | `pgmem/assistance.py` |
| Рівн. (4) оцінка підтримки `S(a_j)`; рівн. (5) правило оприлюднення (θ_low, θ_high) | `pgmem/recall.py` (`GroundedRecall`) |
| Згода, ролі доступу, перевірка дозволу в момент відправлення, ідемпотентність | `pgmem/governance.py` |
| Інваріанти I1–I4 і шість контрприкладів таблиці 2 | `tests/test_contract.py` |
| Рівн. (6)–(7) TSR, FPR, F_ext, C + незалежність, вигадані спогади на 100 відповідей тощо | `pgmem/metrics.py`, `pgmem/stats.py` |
| Протокол оцінювання (розд. 6): три умови на однакових історіях, страти, кластеризація | `pgmem/simulate.py` |
| Генератор синтетичної когорти та історій | `pgmem/synth.py` |
| Метадані датасету (Frictionless Data Package) і валідація | `pgmem/schema.py`, `data/datapackage.json` |

## Датасет (`data/`)

| Файл | Рядків | Зміст |
|---|---|---|
| `participants.csv` | 240 | Метадані учасників: вік, стать, діагноз (MCI / mild_dementia / ABI), CDR, MoCA, PRMQ-P/R, освіта, місяців від діагнозу, проживання, довірена особа, пристрій, цифрова грамотність, сенсори, журнал дзвінків, згоди |
| `episodes.csv` | ~17 000 | Заплановані завдання за 28 днів (ліки, прогулянка, підготовка до прийому, рахунки, дзвінки) |
| `records.csv` | ~3 000 | Персональна база подій із типом доказу, джерелом, κ, згодою, версією |
| `questions.csv` | 4 320 | Запитання про минуле зі стратами: відповідні, без запису, суперечливі, застарілі, обмежені згодою… |
| `reference_history.csv` | — | Незалежна еталонна історія для оцінки тверджень |
| `datapackage.json` | — | Опис кожного поля: тип, опис, діапазон, перелік значень, походження, seed |

## Запуск

```bash
pip install -r requirements.txt
python scripts/run_all.py            # генерує data/, results/, reports/ (≈20 с)
python -m pytest -q tests            # 19 тестів: рівняння, інваріанти, контрприклади
python scripts/build_notebook.py     # перебудувати notebook для Colab
```

Параметри: `--n 500 --days 56 --seed 7 --boot 1000`. Щоб проаналізувати власний (етично схвалений,
псевдонімізований) датасет такої ж структури: `python scripts/run_all.py --data my_data --skip-generate`
(спочатку дані перевіряються за `datapackage.json`).

### Google Colab

Відкрийте `notebooks/PGMem_Colab.ipynb` у Colab (File → Upload notebook) і виконайте всі клітинки
(Runtime → Run all). Код пакета вбудовано в ноутбук, тож нічого додатково завантажувати не потрібно.

## Результати (seed 2026, 240 учасників)

Див. `reports/summary.md` і графіки `reports/fig*.png`. Коротко:

* Запропонована рамка: **0** вигаданих результатів епізодів (I3), **0** контактів після відкликання згоди (I1),
  **0** вигаданих спогадів, **0** тверджень, сильніших за доказ (I2); найнижчий FPR.
* Базовий агент має вищий TSR, але досягає його ескалацією попри відкладення, контактами без чинної згоди та
  перетворенням тиші на «пропущено». За пропозицією P3 статті це не вважається успіхом.
* Покриття відповідей у рамки нижче (≈0.62), бо вона утримується там, де записів немає або вони суперечливі —
  це очікувана ціна (розд. 6: coverage звітується поряд із F_ext).
* У метаданих сильніше за все з результатом пов'язані MoCA і PRMQ-проспективна; група легкої деменції має
  найнижчий TSR і найменшу незалежність — у синтетичній моделі це закладено припущенням, а не виявлено.

## Обмеження

Модель поведінки людей, імовірності відповіді на підказки, шум оцінювача підтримки й частки збоїв — це
параметри симуляції (`pgmem/simulate.py`, `pgmem/synth.py`). Реальні висновки потребують етапів 2–4 протоколу:
спільного проєктування, домашнього пілоту й порівняльного дослідження з етичним схваленням.
