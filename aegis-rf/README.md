# AEGIS-RF — демонстраційний ноутбук (Colab)

**Adversary-rEsistant Geolocation & Integrity for wi-fi Signals.**
Прикладна демонстрація за Розділом 1 дисертаційного дослідження: просторова
ідентифікація джерел IEEE 802.11 у критичній інформаційній інфраструктурі (КІІ) зі
злиттям **RSSI-радіокарти** та **FTM/RTT-дальнометрії**, робастністю до атак
(evil twin, deceptive ranging, deauth) і доказовою атрибуцією (Spatial Attribution
Record) для SOC/SIEM.

## Запуск

Ноутбук [`AEGIS_RF_Demo_Colab.ipynb`](AEGIS_RF_Demo_Colab.ipynb) **самодостатній**: увесь
код інлайновий, зовнішні файли чи клонування репозиторію не потрібні. Потрібні лише
`numpy`, `matplotlib`, `pandas` (усі є в Google Colab за замовчуванням).

* **Colab:** *File → Upload notebook* (або *Open → GitHub*) → **Runtime → Run all**.
* **Локально:** `pip install numpy matplotlib pandas jupyter` і `jupyter notebook`.

## Що всередині

| Розділ | Візуалізація |
|---|---|
| 1. Середовище КІІ та радіомодель | карта AP/зони/подій; теплові карти RSSI-радіокарти |
| 3. Байєсівська локалізація | апостеріорна щільність позиції для однієї події |
| 4. Метрики | стовпчики та лінії медіанної похибки за методами × сценаріями |
| 5. Розподіл похибки | емпіричний CDF та скрипкові діаграми |
| 6. Зонова атрибуція | Pd/FAR-стовпчики та діаграма робочих точок Pd–FAR |
| 7. Просторовий ефект атаки | зміщення оцінок RSSI vs робастне злиття (evil twin) |
| 8. SAR | доказові записи JSON Lines для SOC/SIEM |
| 9. Артефакти | контрольні суми SHA-256 |

Артефакти зберігаються у `results/` (метрики, SAR, маніфест) та `figures/` (рисунки).
