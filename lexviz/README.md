# LexViz 0.1.0

**Legal–Administrative Visualisation Toolkit** — відкритий інструментарій для відтворюваної генерації рисунків
у дослідженнях публічного адміністрування та юстиції. Робочий прототип до рукопису
«Legal Framework for Ukraine’s Post-War Recovery and the EU Acquis» (журнал *Laws*, MDPI).

Один файл даних (YAML) → вісім рисунків статті у форматах PNG 600 dpi (RGB), PDF і SVG.
Кожен елемент рисунка має тег походження твердження:

| Тег | Значення | Колір |
|---|---|---|
| `[L]` | зміст нормативного акта | синій |
| `[EC]` | оцінка Європейської комісії | помаранчевий |
| `[A]` | оцінка авторів | зелений |
| `[P]` | пропозиція авторів | темно-сірий |

## Швидкий старт

### iPad
Див. **[IPAD.md](IPAD.md)**. Коротко: розпакуйте архів у «Файли», відкрийте `run_ipad.py`
у Pythonista 3 або Pyto і натисніть ▶. Готові рисунки вже лежать в `output/`, а
`output/index.html` відкривається в Safari без інтернету.

### Комп’ютер (macOS / Windows / Linux)
```bash
pip install -e .[dev]
lexviz validate data/ukraine_recovery_2026.yaml        # перевірка даних і правил
lexviz build data/ukraine_recovery_2026.yaml -o output # усі 8 рисунків: PNG 600 dpi, PDF, SVG
lexviz build data/ukraine_recovery_2026.yaml -f fig4_compliance_matrix --dpi 300 --formats png
lexviz list                                            # перелік типів рисунків
lexviz palette                                         # перевірка палітри (симуляція порушень кольоросприйняття)
lexviz sync-json data/ukraine_recovery_2026.yaml       # оновити JSON-копію даних (для iPad без PyYAML)
pytest -q                                              # 12 passed
```
Без встановлення: `python -m lexviz build data/ukraine_recovery_2026.yaml`.

## Валідатор: методологія як код
`lexviz/data.py` зупиняє збірку, якщо дані суперечать правилам розділу 2.3 статті:

- C2 «not met» (категоричний відступ) ⇒ оцінка лише «misaligned by derogation», незалежно від інших критеріїв;
- «misaligned by derogation» ⇒ C2 має бути «not met»;
- «aligned» ⇒ усі застосовні критерії виконано; якщо всі виконано — оцінка не може бути «partly aligned»;
- шкала Комісії — лише порядкова (1…5, проміжні рівні на півкроці), і словесне формулювання має відповідати рівню
  («between … and …» для півкроку);
- невідомі теги походження, дати, вузли, типи зв’язків і фази дорожньої карти відхиляються.

Приклад: якщо в `data/ukraine_recovery_2026.yaml` змінити `rating` для `state_aid` на `partly_aligned`, отримаєте
`DATA ERROR: state_aid: C2 not met must be rated 'misaligned by derogation'`.

## Принципи якості
- Сталі кольори тегів походження в усіх рисунках; `[A]` і `[P]` ніколи не зливаються з `[L]` і `[EC]`.
- Колір — не єдиний носій значення: клітинки матриці підписані, оцінки мають піктограми (◐ ✕ ✓), n/a — штриховка.
- Палітру перевірено симуляцією протанопії, дейтеранопії й тританопії (Machado et al. 2009), мінімальна ΔE ≥ 12 (`lexviz palette`).
- Чесні шкали: порядкова шкала Комісії не подається як вимірювання; стиснення часу позначено розривом осі; фази дорожньої карти не прив’язано до календаря.
- Жодного обрізаного тексту: перенесення рядків і висоти блоків обчислюються за фактичною шириною тексту, підписи хронології розміщуються алгоритмом без перекриттів.
- Відтворюваність: однакові дані → побайтово однакові SVG (перевіряє тест); шрифт DejaVu Sans постачається з matplotlib, тож верстка однакова на будь-якому пристрої; у SVG текст перетворено на криві, у PDF шрифти вбудовано.

## Структура
```
lexviz/
├── run_ipad.py                 # запуск на iPad одним натисканням
├── LexViz_iPad.ipynb           # те саме для Carnets / Juno (Jupyter на iPad)
├── IPAD.md                     # інструкція для iPad
├── pyproject.toml              # пакет, залежності, команда lexviz
├── data/ukraine_recovery_2026.yaml   # кодування таблиць 1–2 рукопису (основна копія)
├── data/ukraine_recovery_2026.json   # JSON-дзеркало (працює без PyYAML)
├── lexviz/
│   ├── data.py                 # завантаження та валідація (правило C2 та ін.)
│   ├── style.py                # палітра, кольори походження, вимірювання тексту, експорт
│   ├── palette.py              # валідатор палітри з CVD-симуляцією
│   ├── build.py                # збірка, архів PNG для видавця, HTML-галерея
│   ├── cli.py                  # validate | build | list | palette | sync-json
│   └── figures/                # по модулю на тип рисунка, кожен має draw(dataset)
├── tests/test_dataset.py       # 12 тестів
└── output/                     # згенеровані рисунки (PNG 600 dpi, PDF, SVG, галерея)
```

## Як додати новий тип рисунка
Створіть `lexviz/figures/my_figure.py` з `NAME`, `TITLE` і `draw(d)`, що повертає `matplotlib.figure.Figure`,
і додайте модуль до `_MODULES` у `lexviz/figures/__init__.py`. Інші модулі не змінюються.
