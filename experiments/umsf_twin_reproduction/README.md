# Відтворення еталонного експерименту цифрового двійника кіберполігону УМСФ

Цей каталог містить повне відтворення експерименту, описаного у специфікації
`UMSF_CyberRange_Digital_Twin_Modules_UA.md` (версія 2.0), і звіт про нього.

## Що зроблено

1. **Складання з тексту.** 78 файлів пакета `umsf_twin`, тестового набору й
   конфігурацій механічно вилучено з додатків H–K специфікації
   (`tools/extract_from_spec.py`). Жодного рядка коду не додано, не вилучено
   й не змінено.
2. **Верифікація.** `python3 tests/run_tests.py` — 40/40 перевірок пройдено
   за 3.2 с з першого запуску.
3. **Кампанія.** 5 сценарних прогонів, демонстраційний прогін на 3 репліки,
   латинський гіперкуб на 8 точок, Monte Carlo з послідовною зупинкою.
4. **Звіт.** Дві версії:
   - `Звіт_відтворення_експерименту_umsf_twin.docx` — українською, 14 сторінок,
     структура додатка F специфікації;
   - `UMSF_twin_reproduction_MDPI.docx` — англійською, 10 сторінок, у стилі
     рукопису MDPI (Abstract/Keywords, розділи 1–5, front/back matter,
     нумеровані посилання).
   Обидві супроводжуються PDF-рендерами.

## Результат

Усі 62 контрольні значення розділів K.2–K.8 відтворено точно: хеші
конфігурацій, кількість рядків телеметрії, агрегати мережі, енергетики й
виявлення, довірчі інтервали Monte Carlo. Єдина відмінність —
`engine_source_hash` (`2136f8f4…` замість `925c24c6…`), що є очікуваним
наслідком вилучення вихідних файлів із Markdown: відновлено семантику
реалізації, а не побайтову копію дерева файлів.

Детермінізм підтверджено додатково до штатної перевірки: п'ять сценаріїв,
виконаних повторно у чистому каталозі окремим викликом інтерпретатора, дали
побайтово ідентичні `telemetry.csv`.

## Відтворити

```bash
python3 tests/run_tests.py
python3 -m umsf_twin validate --config umsf_twin/config/inventory/demo.json
python3 -m umsf_twin verify   --config umsf_twin/config/inventory/demo.json
make scenarios doe mc
```

Потрібен лише Python 3.10+; зовнішніх залежностей немає за конструкцією.

Для перегенерації звітів (потрібен npm-пакет `docx`):

```bash
node tools/gen_report.js results/report_data.json out_ua.docx   # українською
node tools/gen_mdpi.js   results/report_data.json out_en.docx   # англійською, MDPI
```

## Склад каталогу

| Шлях | Вміст |
|---|---|
| `umsf_twin/` | пакет, вилучений зі специфікації (66 модулів + 8 конфігурацій JSON) |
| `tests/run_tests.py` | набір із 40 перевірок восьми категорій |
| `tools/extract_from_spec.py` | вилучення файлів із Markdown-специфікації |
| `tools/gen_report.js` | генератор українського звіту DOCX з артефактів прогонів |
| `tools/gen_mdpi.js` | генератор англійського рукопису DOCX у стилі MDPI |
| `results/*.json` | вихід команд `validate`, `verify`, `doe`, `mc` і зведені дані звіту |
| `results/runs/` | маніфести, зведення, `report.md` і `alerts.csv` кожного прогону |
| `README.upstream.md` | README пакета з самої специфікації |

`telemetry.csv` і `ground_truth.csv` навмисно не комітяться: вони
детерміновано відтворюються командами вище, а SHA-256 кожного з них
записано в `results/runs/<run>/manifest.json`.

## Межа твердження

Усі числа є виходом програмної моделі за заданих припущень. Вони не є
вимірюваннями фізичного кіберполігону УМСФ. Чотири параметри мають статус
`UNKNOWN` і програмно блокують режим HIL; режими EMU та HIL у реалізації не
виконуються.
