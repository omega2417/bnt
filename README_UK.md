# SatQKD-Sentinel 2.0.2 — інструкція запуску

**Google Colab:** open `COLAB_START.ipynb` using **File → Upload notebook**, then **Runtime → Run all**. Only this notebook is needed; all project code and tests are embedded. See [START_COLAB.md](START_COLAB.md).

Самодостатній дослідницький проєкт для моделювання супутникових QKD-каналів, GEO-покриття, оптичних фазованих решіток і розпізнавання синтетичних збоїв та атак. Вихідний код, тести, демонстрація, приклади результатів і пояснення містяться в архіві. Стаття, зовнішні дані, облікові записи та API-ключі для запуску не потрібні.

## Найшвидший перегляд

Відкрийте `results/demo/report.html` у браузері. Це вже сформований звіт з усіма зображеннями всередині, доступний без Python та інтернету. На планшеті або телефоні можна переглядати цей звіт; нові обчислення потребують комп’ютера з Python.

## Запуск нових обчислень

Потрібен **Python 3.10 або новіший**; перевірено на Linux із Python 3.12.14. Рекомендовано Python 3.12. Інтернет потрібний лише для першого встановлення бібліотек. Інтерпретатор Python і бібліотеки сторонніх розробників не вбудовано в ZIP. Після встановлення всі обчислення працюють локально без мережевих сервісів.

1. Повністю розпакуйте архів у звичайну папку.
2. **Windows:** запустіть `start.bat`. **Linux / macOS:** у цій папці виконайте `sh start.sh`.
3. Дочекайтеся повідомлення `Report:` та відкрийте `results/demo/report.html`.

Скрипт створює `.venv`, встановлює проєкт і запускає демонстрацію. Наявні результати в цільовій папці перезаписуються; для іншого експерименту вкажіть окремий `--output`.

### Ручне встановлення

```bash
python -m venv .venv
```

Активуйте середовище: Windows — `.venv\Scripts\activate`; Linux/macOS — `source .venv/bin/activate`. Потім:

```bash
python -m pip install -r requirements.txt
python run.py demo
```

Для відтворення перевіреного набору версій на Python 3.12:

```bash
python -m pip install -r requirements-tested-py312.txt
python -m pip install .
```

## Команди

```bash
# Діагностика встановлених версій
python run.py doctor

# Швидкий цикл: Random Forest, 30 навчальних і 20 тестових прольотів
python run.py demo --seed 42 --output results/demo

# Порівняння трьох класифікаторів на окремих train/validation/test прольотах
python run.py demo --full --train 40 --test 20 --output results/full

# Синтетична телеметрія: рівно 50 прольотів
python run.py simulate --passes 50 --seed 7 --output results/new_telemetry.csv

# Прогноз збереженою моделлю; мітка label у CSV не обов’язкова
python run.py predict --model results/demo/model.joblib --input results/new_telemetry.csv --output results/new_predictions.csv
```

Також доступні `python -m satqkd_sentinel` та, після встановлення, `satqkd-sentinel`. Навчальні файли `.joblib` завантажуйте лише з довіреного джерела. Модель прив’язана до версії проєкту і scikit-learn; після зміни версій повторіть `demo`, щоб перенавчити її.

## Наукові припущення та межі

- Дані синтетичні; значення F1 характеризують розпізнавання заданих симулятором сигнатур, а не підтверджену точність на реальній супутниковій системі.
- Ознаки є причинними в межах прольоту: поточне й минулі вікна, без майбутніх спостережень. `anomaly_distance` — RMS нормованих фізичних залишків із фіксованими масштабами, не статистична Mahalanobis-відстань. Окремий Mahalanobis-детектор калібрується на навчальних номінальних даних.
- Геометрія — сферична Земля, двотільний рух, ідеалізовані GEO-позиції. Для базового каналу: висота 500 км, 1550 нм, апертури 0.1 / 0.6 м; усі параметри відкриті в `Link`.
- Finite-key є **спрощеною ілюстративною оцінкою**; оцінка флуктуацій і фазової похибки не реалізує повний доказ composable security. Вона враховує спостережувані помилки сигналу та розбиття на блоки. Не використовуйте її результат як дозвіл видавати реальний криптографічний ключ.
- Асимптотична модель рахує всі імпульси як signal; finite-size модель використовує signal/weak/near-vacuum = 50/25/25%. Їх різниця включає і скінченний розмір вибірки, і розподіл інтенсивностей.
- `rate_bps` і `key_bits` під час аномалій — модельні оцінки, а політики відбору — порівняння сценаріїв. Атаки не можна визнати безпечними лише за рішенням ML.
- `network_availability` моделює незалежні доступні канали; вона не є розрахунком зв’язності довільної кільцевої топології.
- Стандартний крок OPA 2 мкм при 1550 нм допускає дифракційні пелюстки. `steering_range` — головний кутовий інтервал, а не гарантія їх відсутності.
- Схема федеративної архітектури є ілюстрацією; розподілене федеративне навчання та робота з фізичним QKD-обладнанням не реалізовані.
