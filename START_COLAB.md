# Почніть тут: Google Colab

1. Розпакуйте цей ZIP на своєму пристрої.
2. Відкрийте https://colab.research.google.com/ і увійдіть у свій Google-акаунт.
3. Виберіть **File → Upload notebook** і завантажте **`COLAB_START.ipynb`** із кореня архіву.
4. Залиште звичайний **CPU**. Виберіть **Runtime → Run all** («Середовище виконання → Виконати всі»).
5. Дочекайтеся завершення всіх **34 комірок коду**. Навчання та тести можуть тривати кілька хвилин.
6. Наприкінці натисніть **«Завантажити результати»**. ZIP результатів містить HTML-звіт, 13 PNG-графіків, CSV-таблиці, JSON-параметри, навчену модель і протокол тестів.

**У Colab потрібно завантажити лише один файл `COLAB_START.ipynb`.** Не завантажуйте ZIP у вікно Upload notebook. Код усіх модулів і тести вже вбудовані в ноутбук. Не потрібні розпакування архіву в `/content`, ручні зміни шляхів, GitHub, Google Drive, API-ключі або GPU.

`notebooks/demo_satqkd_sentinel.ipynb` є ідентичною автономною копією. `notebooks/COLAB_VERIFIED.ipynb` містить результати перевіреного локального виконання; для нового запуску вибирайте `COLAB_START.ipynb`.

## Якщо окрему комірку запущено не по порядку

Обчислювальні комірки використовують змінні з попередніх комірок. Після нового підключення, перезапуску або видалення середовища виконайте **Runtime → Run all**. `NameError` після запуску комірки із середини означає, що попередні комірки ще не виконані.

## Залежності

Перша комірка встановлює лише відсутні бібліотеки. Вона не замінює без потреби вже встановлені в Colab NumPy/pandas/scikit-learn. Якщо бібліотеки старіші за мінімально підтримувані, комірка назве їх і зупиниться з інструкцією оновлення та перезапуску. Якщо встановлення заблоковано відсутністю інтернету, спочатку відновіть доступ і повторіть Run all.

## Що саме перевірено

- Відтворено `ModuleNotFoundError` у першій комірці початкового ноутбука.
- Новий `.ipynb` перевіряється як єдиний файл у чистій папці, у середовищі **без встановленого `satqkd_sentinel`**.
- Код відновлюється з вбудованого архіву з перевіркою SHA-256; всі комірки виконуються зверху вниз без пропусків.
- Перевірка Python/IPython не є перевіркою інтерфейсу або хмарної VM Google. Фактичний сеанс Google Colab і натискання кнопки завантаження на його серверах не виконувалися.
- Детальні результати виконання збережено в `verification/colab_cells.json`, `verification/colab_summary.json` і виконаному ноутбуці.

Збережіть результати перед завершенням сеансу: середовище Colab тимчасове. Документація Google: https://research.google.com/colaboratory/faq.html
