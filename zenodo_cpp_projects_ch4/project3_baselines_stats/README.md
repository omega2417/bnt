# Проєкт 3 (Розділ 4). Baseline-методи та статистичний план порівняння (§4.3)

**Baseline Localizers and Paired Statistical Comparison**

Референсна реалізація підрозділу **4.3** (пп. 4.3.2–4.3.5 baseline-методи;
п. 4.3.8 добір параметрів, повтори та статистичний аналіз). Програма мовою
**C++17** без зовнішніх залежностей, орієнтована на **OnlineGDB** і будь-який
`g++`/`clang++` (>= C++17) чи MSVC.

---

## 1. Baseline-методи (на однакових даних і бюджеті, §4.3.1)

На синтетичній статистичній радіокарті (5 AP, log-distance path loss) із survey
на сітці RP локалізуються заморожені test-точки чотирма методами:

| Метод | Підрозділ |
|---|---|
| RSSI path-loss **трилатерація** (лінійний LS) | §4.3.2 |
| **WKNN** fingerprinting (inverse signal-distance ваги) | §4.3.3 |
| **імовірнісний** RSSI (Horus/Roos-style гаусів likelihood) | §4.3.4 |
| **proposed** — робастний WKNN на щільнішому survey | (метод, що перевіряється) |

## 2. Статистичний план (§4.3.8)

Парні похибки (ті самі test-точки, згруповані в session/site **блоки**) подаються
на:

- **block bootstrap** 95% ДІ для MAE та для **парної різниці** MAE (ресемпл блоків) [104];
- **Wilcoxon signed-rank** тест + **Hodges–Lehmann** медіана різниці [107];
- **McNemar** тест для парних зональних правильностей [106];
- **Cliff's delta** — непараметричний розмір ефекту [121];
- **Holm–Bonferroni** контроль множинності по родині порівнянь;
- **Friedman** статистика + **Nemenyi** critical difference по всіх методах [108].

## 3. Ключовий висновок демонстрації

`proposed` перевершує трилатерацію з **великим** ефектом (Cliff's delta ≈ 0,63,
Wilcoxon `p≈7e-21`, ДІ різниці не містить 0). Проте `proposed` vs `WKNN`/
`probabilistic` дає **статистично значущу**, але **мізерну** (negligible) різницю
MAE **без** покращення зональної правильності (McNemar незначущий). Саме це
ілюструє §4.3.8: **нижча MAE сама по собі не є науковим твердженням** — вона
подається з ДІ, парним тестом, розміром ефекту й поправкою на множинність.
Bootstrap ресемплює **блоки**, а не кадри, бо кадри всередині сесії не є
незалежними повтореннями.

## 4. Очікуваний результат (фрагмент)

```
   trilateration            MAE=7.061 m   zonal_acc=0.828
   proposed(robust+dense)   MAE=2.598 m   zonal_acc=0.906
trilateration vs proposed: Wilcoxon z=9.37 p=7e-21  Cliff's delta=0.630 (large)
WKNN(k=4)     vs proposed: Wilcoxon p=2.6e-02  Cliff's delta=0.086 (negligible)
Friedman statistic=110.5  Nemenyi CD=0.350
```

## 7. Наукові застереження

Синтетичні числа — **ілюстрація**, не результати дисертації. p-значення
обчислюються нормальним/χ² наближенням; для реальних даних застосовуються
block-рівневі повтори, nested validation добору параметрів і повний звіт effect
size + multiplicity (§4.3.8). Робочі точки — **to_be_validated**.
