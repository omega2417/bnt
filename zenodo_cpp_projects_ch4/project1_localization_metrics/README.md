# Проєкт 1 (Розділ 4). Оцінювання локалізаційної якості (§4.4)

**Localization-Quality Evaluation for Spatial Attribution**

Референсна реалізація підрозділу **4.4** — повна панель метрик локалізаційної
якості з відокремленням точкової точності від чесності та гостроти
апостеріорного розподілу. Програма мовою **C++17** без зовнішніх залежностей,
орієнтована на **OnlineGDB** і будь-який `g++`/`clang++` (>= C++17) чи MSVC.

---

## 1. Що обчислюється

| Метрика | Підрозділ |
|---|---|
| MAE, median, RMSE, MAD, 20% trimmed mean | §4.4.2 |
| емпірична CDF/CCDF, P50/P75/P90/P95/P99 | §4.4.3 |
| зональна правильність (загальна + по зонах) | §4.4.4 |
| availability, time-to-localize | §4.4.5 |
| HPD coverage на рівнях 50/80/90/95 %, area, sharpness \| coverage | §4.4.8 |
| зональний Brier score, NLL | §4.4.8 |
| block bootstrap 95% ДІ (ресемпл **блоків**, не кадрів) | §4.3.8 |
| trajectory-aware агрегація (within-then-between) | §4.4.2 |

**HPD coverage** для 2-D ізотропного гаусового posterior обчислюється точно:
радіальний зсув `r` має розподіл Релея, тож HPD-радіус рівня α дорівнює
`R(α)=σ·√(−2 ln(1−α))`, а покриття — емпірична частка `r ≤ R(α)`; area = `πR²`.

## 2. Демонстрація

Два arm-и на **однакових** заморожених епізодах:

- **baseline** — вища MAP-похибка й **занижена** заявлена `σ` → HPD coverage
  **нижче** номінального рівня (over-confident, небезпечно для AUTO);
- **proposed** — менша похибка й **чесна** `σ` → coverage ≈ номіналу.

Саме це є головним висновком §4.4: **точкова точність (MAE/median/RMSE)
відокремлена від honesty (HPD coverage) і sharpness**. Метод із меншою MAE, але
покриттям нижче номіналу, є надмірно впевненим.

> Порівняння arm-ів статистичними тестами — предмет Проєкту 3 (§4.3).

## 3. Запуск на OnlineGDB

Відкрийте <https://www.onlinegdb.com> → мова **C++** → вставте `src/main.cpp`
→ **Run** (введення не потрібне; RNG детермінований — результат відтворюваний).

## 4. Локальна збірка

```bash
make run
# або: g++ -std=c++17 -O2 src/main.cpp -o localization_metrics && ./localization_metrics
```

## 5. Наукові застереження

Синтетичні числа є **ілюстрацією**, а не результатами дисертації. micro-average
по кадрах не використовується як основна оцінка (§4.4.2); ДІ отримуються block
bootstrap, бо кадри всередині сесії не є незалежними повтореннями (§4.3.8).
Робочі точки — **to_be_validated**.
