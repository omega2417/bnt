# Synthetic data of this deposit

Every data file in this package is **synthetic**: generated by the software model
in SIM mode. Nothing here was measured on the physical UMSF cyber range.

## Where the record-level data lives

Record-level synthetic data is stored inside the run directory that produced it,
so that each file stays bound to its own configuration, seed and manifest. It is
deliberately **not duplicated** here, because a second copy would have a separate
checksum and could drift from the run it belongs to.

| Data | Location |
|---|---|
| Synthetic telemetry | `results/*/telemetry.csv`, `results/*/*/telemetry.csv` |
| Scenario-generated ground truth | `results/*/ground_truth.csv` |
| Alerts | `results/*/alerts.csv` |
| Response audit | `results/*/response_audit.json` |
| Parameters with evidence status | `results/*/parameters.json` |
| Resolved configuration | `results/*/scenario.resolved.json` |
| Aggregated metrics | `results/*/summary.json` |
| Integrity manifest | `results/*/manifest.json` |
| Index of every independent run | `results/run_index.csv` |

Field definitions: `docs/data_dictionary.md`.

## Volume

| Component | Independent runs/replicates | Telemetry rows |
|---|---:|---:|
| Five SIM scenarios | 5 | 7,627 |
| Demonstration run | 3 | 5,422 |
| Exploratory DoE | 8 | 14,442 |
| **Total** | **16** | **27,491** |

The figure of 13,049 rows quoted in the report and in the Zenodo description is
the scenario + demonstration subtotal (7,627 + 5,422), reported separately from
the DoE rows so that neither number inflates the other.

**Rows inside one run are dependent.** No row total in this package is an
independent sample size; the unit of analysis is the run/replicate.

## Provenance vector

`stimulus_origin = scripted_synthetic` · `observation_origin = simulator_output` ·
`label_origin = scenario_controller` · `curation_origin = automated_pipeline` ·
`analysis_origin = derived_metric`

The values `measured`, `physical_sensor` and `cyber_range_instrumentation` do not
appear in this deposit and must not be introduced without a separate evidence
package containing primary logs.

## Reuse condition

The data is licensed CC BY 4.0 (`LICENSES/`). One attribution condition survives
redistribution: **it may not be reused, cited or merged as measured, field or
sensor data.**
